# Discovered Auth Patterns

This file contains authentication patterns discovered during AuthScan analysis and **confirmed by the user**. Patterns are only added here after explicit user approval — AuthScan never writes to this file automatically.

## Format

Each entry should follow this structure:

```
## {Pattern Name}
- **Framework/Language:** {info}
- **Search keywords:** `keyword1`, `keyword2`
- **Mechanism:** {description}
- **Trust anchor source:** {how the anchor is obtained}
- **Example:**
  ```{language}
  {code}
  ```
- **Discovered in:** {project_name}, {date}
```
